# Paddock Desktop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Paddock, the Electron desktop app that watches WorkHorse repositories, drives runs through the installed `claude` CLI, animates a palette-painted thinking orb from live agent events, and lets the user open gates.

**Architecture:** Electron main process owns filesystem, child processes, settings and the API key, and exposes a typed IPC bridge through a preload script. The renderer is a React app that renders purely from a Zustand store fed by IPC events. A pure `normalise()` function turns Claude's `stream-json` messages into a small set of run events; phase and gate come from a file watcher that re-runs `wh.js digest`, not from the stream.

**Tech Stack:** Electron 44.3, electron-vite 5, React 19.3, TypeScript 5.9, Zustand 5, chokidar 5, react-markdown 10 + remark-gfm 4, thinking-orbs 0.3.1 (engine subpath only), vitest 5, @playwright/test 1.63, electron-builder 26.15. Optional: @anthropic-ai/claude-agent-sdk 0.3.268 (dynamic import, SDK backend only).

**Spec:** `docs/superpowers/specs/2026-09-10-paddock-desktop-design.md`

## Global Constraints

- App lives at `desk/` inside the WorkHorse repository. All paths below are relative to `desk/` unless they start with `../`.
- Node 18+ required at runtime; `claude` on PATH for the CLI backend. Verified by `syscheck` before anything else renders.
- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`. Renderer CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'none'`.
- Child processes use argument arrays, never a shell string. Every IPC handler that touches a repo takes a `repoId` and resolves the path from the registry; the renderer never sends a filesystem path except through `repos.add` after a native dialog or drop.
- `artifact.read` accepts only `relPath` under `docs/sdlc/` with no `..` segment.
- API key only via `safeStorage`; never logged, never returned to the renderer.
- Dark theme only. Every colour is a CSS token from spec section 4.1. No literal colours in components.
- Fonts bundled as woff2 under `resources/fonts/`; no network font loading.
- Commits use conventional messages prefixed `desk:` for scope, e.g. `feat(desk): …`.
- Tests: `npm test` runs vitest; every task's tests must pass before its commit. Coverage floors are not enforced; correctness is.
- No `Date.now()` in the renderer for elapsed times; `at` timestamps come from main.

`scripts/sync-plugin.js`:

```js
#!/usr/bin/env node
// Copies the WorkHorse plugin (repo root) into resources/plugin so the app can bundle it.
'use strict';
const fs = require('node:fs');
const path = require('node:path');
const ROOT = path.resolve(__dirname, '..', '..');
const DEST = path.resolve(__dirname, '..', 'resources', 'plugin');
const INCLUDE = ['.claude-plugin', 'agents', 'skills', 'hooks', 'scripts', 'templates', 'README.md'];
fs.rmSync(DEST, { recursive: true, force: true });
fs.mkdirSync(DEST, { recursive: true });
for (const entry of INCLUDE) {
  const src = path.join(ROOT, entry);
  if (!fs.existsSync(src)) continue;
  fs.cpSync(src, path.join(DEST, entry), { recursive: true, filter: (p) => !/[\\/](node_modules|tests)[\\/]?/.test(p) });
}
const manifest = JSON.parse(fs.readFileSync(path.join(DEST, '.claude-plugin', 'plugin.json'), 'utf8'));
fs.writeFileSync(path.join(DEST, 'VERSION'), manifest.version + '\n');
console.log(`synced plugin ${manifest.version} -> ${path.relative(process.cwd(), DEST)}`);
```

### Task 2: Stream normaliser

**Files:**
- Create: `src/main/drivers/normalise.ts`

**Interfaces:**
- Produces: `createNormaliser(now: () => number): (msg: unknown) => RunEvent[]`. Stateful: remembers `task_id -> subagent_type` and `tool_use_id -> task_id` so later events can be attributed.

Mapping (from the recorded fixture):

| Incoming | Emits |
|---|---|
| `{type:'system',subtype:'init',session_id,plugins:[{name}],skills:[…]}` | `init` with plugin names and skills |
| `{type:'system',subtype:'task_started',task_id,tool_use_id,subagent_type,description}` | `agent:start`; remember `task_id -> subagent_type` and `tool_use_id -> task_id` |
| `{type:'system',subtype:'task_progress',task_id,last_tool_name,usage:{total_tokens,tool_uses}}` | `agent:progress` |
| `{type:'system',subtype:'task_notification',task_id,status,summary,usage:{total_tokens,duration_ms}}` | `agent:stop` with the remembered type (fall back to `'agent'`) |
| `{type:'system',subtype:'task_updated',task_id,patch:{status:'completed'}}` | `agent:stop` **only if** no `task_notification` was seen for that id (dedupe by a `stopped` set) |
| `{type:'assistant',message:{content:[{type:'tool_use',id,name}]},parent_tool_use_id}` | one `tool` per block; `agentId` = task for `parent_tool_use_id` if known |
| `{type:'assistant',message:{content:[{type:'text',text}]},parent_tool_use_id}` | one `text` per non-empty block |
| `{type:'user',message:{content:[{type:'tool_result',tool_use_id,is_error}]},parent_tool_use_id}` | `tool:result` |
| `{type:'rate_limit_event',rate_limit_info:{status,utilization}}` | `notice` with text like `rate limit 76% (seven_day)` only when `status !== 'allowed'` |
| `{type:'result',subtype,total_cost_usd,num_turns,duration_ms,session_id}` | `result` |
| anything else (`hook_*`, `thinking_tokens`, `task_summary`, `post_turn_summary`, `thinking` blocks) | nothing |
